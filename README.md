# 虎扑 Excel · 摸鱼模式

把 `bbs.hupu.com` 伪装成一个 Excel 工作簿的油猴脚本（Tampermonkey / Violentmonkey / Greasemonkey）。

- 脚本文件：**`hupu-excel.user.js`**
- 参考实现：[`reference/nga-excel.js`](reference/nga-excel.js)（NGA 优化摸鱼体验的 Excel 模式）、[`reference/nga-codex.user.js`](reference/nga-codex.user.js)（数据读取 / 结构化渲染的思路）

## 安装

1. 浏览器装好 Tampermonkey（或 Violentmonkey）。
2. 打开 Tampermonkey 面板 → 添加新脚本 → 把 `hupu-excel.user.js` 全文粘进去 → Ctrl+S。
3. 打开 <https://bbs.hupu.com/bxj> 之类的版面页即可。

| --- | --- |

## 底部工作表标签 = 页面自己的分区

首页和版面页的左侧栏都是同一套导航（`我的关注` + `话题广场`），所以这两张表在两个页面上都有，底部标签直接对应页面分区，点一下就能在「这个版面的帖子」「我关注的/热门板块」「全站板块目录」之间切：

```
社区首页  →  我的关注 │ 话题广场 │ 站内热帖
版面页    →  步行街主干道 │ 我的关注 │ 话题广场 │ 版主
帖子页    →  全部楼层 │ 热帖 │ 最新      （帖子页没有左侧栏）
```

未登录时「我的关注」表首行会有一条灰色说明，下面跟热门板块（来源列标「热门」）；登录后关注的板块排在最前（来源列标「我的关注」）。首页底部的工作表标签直接对应页面左侧栏的分区（我的关注 / 话题广场），点标签就能在「我关注的板块」「全站板块目录」「热帖」之间切。

## 它是怎么工作的

**数据读取**（结构化数据优先，DOM 兜底）

| 来源 | 拿到什么 |
| --- | --- |
| 内联 `window.$$data`（列表页 `topic`、首页 `pageData`） | 列表页：49 条帖子（含 **点亮数**）、热门专区、版主列表、分页；首页：我的关注 `follow`、20 个热门板块、13 个分类、**70 条**推荐流 |
| 页面左侧栏 DOM（首页、版面页都有） | 「话题广场」区 13 个分类下的**完整** 255 个板块（内联 JSON 里每个分类只带了前几个，所以名单以 DOM 为准，热度数字用 JSON 覆盖成精确值）；「我的关注」区登录后就是真实关注列表 |
| `<script id="__NEXT_DATA__">`（帖子页 SSR） | 标题 / 正文 / 楼层 / 点亮 / 属地 / 客户端 / 分页 |
| DOM 解析 | 上面都拿不到时的兜底 |

**伪装**

- 原生 DOM 只是 `display:none` 藏起来（不移除），站点自己的 JS、登录态、埋点都照常；
- **站内链接走软导航**：`fetch` 回目标页 HTML、解析出数据后在同一个文档里重画，浏览器不换文档，所以切版面 / 进帖子 / 翻页不再闪原生页面（拿不到数据或失败时退回整页跳转）；
- **首帧就是 Excel**：`document-start` 时先给 `<html>` 打上锁，`<body>` 一出现就把外壳（标题栏/功能区/编辑栏/「正在打开 工作簿1.xlsx…」）立起来，数据等 `DOMContentLoaded` 再填 —— 真实站点从首帧到 DCL 有 1～2 秒，不等它，否则那段时间是白屏／原生页面；
- 隐藏规则是「`body` 下除了 `#hx-root` 全隐」，不写死 `#container` / `#__next`：错误页、WAF 拦截页、以后改版的容器都不会漏出来；
- 带看门狗：万一站点把我们加的 `hx-on` / `#hx-root` 弄掉（或者脚本注入晚了），`readystatechange` / `pageshow` / `focus` 和几个定时器会把状态拉回来；
- 自己画整窗 Excel：标题栏 / 选项卡 / 功能区 / 编辑栏 / 行列标（A…Z、AA…）/ 冻结窗格 / 工作表标签 / 状态栏 / 缩放条，3 套皮肤；
- 账号区读页面顶部 `.hp-topLogin-info`（站点 JS 异步填的昵称与头像），并用 MutationObserver 跟着刷新；
- 全部图标是内联 SVG，favicon 是即时生成的 SVG data URI，**不依赖任何外部资源**；
- 样式全部限定在 `#hx-root` 内并做了一层 scope reset，不会被虎扑的 CSS Modules 串味；
- 单元格支持选中（绿色选中框 + 名称框/编辑栏联动）、行号列标高亮、长内容自动换行并可滚动；
- 帖子图片以缩略图贴在单元格里（尺寸可在设置面板里调），**鼠标悬停会在旁边浮出原图并标出尺寸**：原图地址自动取 `data-origin`，没有的话去掉虎扑图床的缩放参数（`x-oss-process=image/resize,w_800` / `imageMogr2/…`）就是原图。

## 为什么「有时候会闪一下原生页面」

### 页面内切换：已经修掉了（软导航）

虎扑是**多文档**站点：点版面、点帖子标题、点下一页原本都是整页跳转。整页跳转会创建一份新文档，而油猴只能在 `document-start` 注入脚本 —— 新文档从创建到第一次绘制可能只有 ~30ms，脚本还没来得及挂锁，那一小段画出来的就是原生页面。这个窗口在页面里没法再往前压（脚本已经是在 `document-start` 干的第一件事）。

从 v1.1.0 起，Excel 自己 UI 里的**站内**链接不再让浏览器换文档：

1. 捕获阶段 `preventDefault()` 拦下点击，`history.pushState` 同步地址栏；
2. `fetch` 回目标页的 HTML，`DOMParser` 解析成一份游离文档；
3. 把同一套数据读取逻辑（`window.$$data` / `__NEXT_DATA__` / DOM）指向这份文档，在**同一个文档**里重画 Excel。

文档全程不换，所以**切版面 / 进帖子 / 翻页都不会再闪原生页面**。拿不到模型（搜索页、个人中心…）或请求失败时会自动退回原来的整页跳转；外部链接（`my.hupu.com`、其它站）保持原样。前进/后退也能用：`popstate` 会重新拉一份对应地址的 HTML 渲染。

切过去之后会落到**新页面自己的默认工作表**：从「话题广场」里点一个版面，就自动切到那个版面的帖子表，滚动位置也从头开始 —— 跟原来整页跳转的效果一致（同一页面内改设置的重绘则会留在你原来那张表上）。

面包屑里的每一节现在都有对应的表，不会再落到「没有数据」的兜底页：`社区` → 首页、`步行街` 这类**分类页**（`/all-*`，数据在 `$$data.pageData` 里）→ 分类帖子流 + 该分类下的板块、版面名 → 版面帖子表、帖子标题 → 帖子楼层。

代价：软导航过的页面，物理 DOM 还是上一次整页加载的那份。所以软导航之后按 `Esc`（老板键）或 `Alt+E` 关掉 Excel 模式时，脚本会**重新加载当前地址**，并在新文档里直接进原生模式，保证看到的原页面是对的。

### 首次打开 / 整页加载：还是油猴注入时机问题

下面这段只影响**冷启动那一页**（直接打开链接、刷新、从站外点进来），页面内切换已经由软导航接管。

在真站点上逐帧打点（new document 里挂 `requestAnimationFrame`，记录每一帧 `<html>` 有没有锁、`#container` 可不可见、Excel 外壳在不在），用 Edge/Chromium 内核测：

| 场景 | document 创建 → 第一次绘制 | 结果 |
| --- | --- | --- |
| 冷加载（DNS/TLS 都要建） | ~2.7 秒 | 脚本怎么都来得及 |
| **热加载（正常浏览）** | **~30 毫秒** | 谁慢谁输 |

| 脚本注入延迟 | 原生页面可见帧 |
| --- | --- |
| 0ms（Chrome 的 `document_start`，等价 `evaluateOnNewDocument`） | **0 帧** |
| 100ms | **7 帧（约 100ms，就是「闪一下」）** |

也就是说：**hupu 热缓存页面从 document 创建到第一次绘制只要 ~30ms**，而 Tampermonkey 的 `@run-at document-start` 注入要先跟后台 service worker 往返一次（冷启动几十~几百 ms，醒着时也要几十 ms），这段时间脚本还没开始跑 —— 页面里做什么都拦不住。脚本自己从开始执行到挂上锁只要 ~8ms（锁是第一条语句，连配置都还没读），已经压不动了。

> 设置面板「关于」页现在会显示一行**启动时序**（控制台也会在晚了的时候打一条 `[hupu-excel] 脚本注入晚了 Xms` 的警告）：
> `脚本开始 192ms · 挂锁 194ms · Excel 外壳 194ms · 首帧 200ms · ✓ 挂锁早于首帧 6ms`
> 如果这里显示 `⚠ 挂锁比首帧晚了 Xms`，那就是油猴注入时机的问题，不是页面里的问题。

### 想彻底消掉（可选，需要另一个扩展）

CSS 由浏览器扩展在**首帧之前**注入，跟脚本注入时机无关。脚本已经配合好了：Excel 模式关掉或按 Esc 时都会给 `<html>` 挂上 `hx-peek`，所以下面这些规则只用 `html:not(.hx-peek)` 一个条件就够了 —— 不会在你关掉脚本后把页面藏没。

**uBlock Origin**（设置 → 我的过滤器，加两行）：

```
! 首帧就把虎扑原生页面藏掉（脚本还没跑起来也不会露）
bbs.hupu.com##html:not(.hx-peek) > body > *:not(#hx-root)
! 顺便把首帧刷成 Excel 的样子：顶上一段绿色标题栏 + 一条浅灰分隔线
bbs.hupu.com##html:not(.hx-peek):style(background:linear-gradient(#217346 0px,#217346 44px,#e1dfdd 44px,#e1dfdd 46px,#ffffff 46px) fixed !important)
```

**Stylus** 新建一个样式，匹配 `bbs.hupu.com`：

```css
html:not(.hx-peek) > body > *:not(#hx-root) { display: none !important; }
html:not(.hx-peek) { background: linear-gradient(#217346 0, #217346 44px, #e1dfdd 44px, #e1dfdd 46px, #fff 46px); }
```

这样首帧已经是「绿标题栏 + 白表格」的样子，然后脚本的外壳无缝接上，肉眼看不到任何原生页面。

### 顺带做的加固

- 隐藏规则单独抽成一个不分词的 `<style id="hx-hide">`（不走 16KB 的 scopeCss 正则），从脚本开跑到能画第一帧之间的开销压到最低；
- `<body>` 一出现就立外壳，首帧是「正在打开 工作簿1.xlsx…」而不是白屏 / 原生页面；
- 看门狗（`readystatechange` / `pageshow` / `focus` + 定时器 + 监听 `<html>` 的 class 和 `body` 子节点）在**微任务级**回补被站点弄掉的 `hx-on` 和 `#hx-root`；
- `@match` 放宽到 `*.hupu.com`：作者名链到 `my.hupu.com`、正文里的 `news/www.hupu.com` 链接不会再把原生页面露出来（这些页面上会显示一张「没有数据」的说明表，按 Esc 可以看原页面）。
